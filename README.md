# Онлайн-бронирование столика в ресторане

Асинхронный бэкенд-сервис на FastAPI для управления бронированиями столов.

## Как запустить проект локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd ИМЯ_РЕПОЗИТОРИЯ
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   # Для macOS/Linux:
   source .venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install fastapi "uvicorn[standard]" sqlalchemy aiosqlite pydantic
   ```

4. **Запустите приложение:**
   ```bash
   python main.py
   ```
   *База данных SQLite создастся автоматически при первом запуске приложения благодаря встроенному lifespan-контексту.*

5. **Откройте документацию:**
   Перейдите в браузере по адресу: [http://127.0.0](http://127.0.0)

## Принятые решения и архитектура

1. **Асинхронность и производительность**: Проект реализован на асинхронном стеке (`FastAPI` + `SQLAlchemy 2.0` + `aiosqlite`), что обеспечивает высокую пропускную способность при работе с базой данных без блокировки потоков.
2. **Надежная валидация на входе**: Проверка корректности данных (формат российских номеров телефона, буквенные имена, лимиты гостей и валидация часовых слотов с 12:00 до 22:00) вынесена в Pydantic-схемы с использованием `@field_validator`, что позволяет отсекать некорректные запросы до обращения к БД.
3. **Мягкое удаление (Soft Delete)**: Для эндпоинта `DELETE /bookings/{id}` не менялся статус записи на `cancelled` вместо физического удаления строки, чтобы бизнес мог иметь историю бронирований и строить аналитику.
4. **Защита от повторной записи**: В логику создания брони встроен фильтр, который проверяет занятость даты и времени только среди `active` записей, автоматически освобождая слоты при их отмене.
5. **Разделенный код**: Логика работы с базой данных отделена от эндпоинтов и вынесена в отдельные функции, что упрощает дальнейшую поддержку кода.
